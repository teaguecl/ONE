# Bank-qualified breakpoints (bpx / bpm BB:ADDRESS) on the MMC1 test ROM (tests/mmc1): once a frame the main loop
# maps PRG bank k at $8000 (k = frame & 7), sets X = k and reads $8000 from the fixed bank 7 (A = $11 * k).
bpm 03:8000 r
x
!assert reg x 03
!assert reg pc c114
bc *
bpm 05:8000 r
reset hard
x
!assert reg x 05
bc *
# bank 3 is not what is mapped at $C000 (bank 7 is): that breakpoint never fires, the one after it does
bpx 03:C114
bpx 07:C114
reset hard
x
!assert reg pc c114
bc *
# refused: no such bank, not a PRG address, not a number
bpx 7F:8000
bpx 03:0300
bpx zz:8000
bl
# a range with a bank prefix: the bank applies to the whole range, and the stop comes in the frame that maps that bank (X = bank)
reset hard
bpm 05:8000..9FFF r
x
!assert reg x 05
bc *
reset hard
bpm 03:8000..9FFF r
x
!assert reg x 03
bc *
# F9 (the toggle) sets a breakpoint for the bank that is mapped at the address now (bank 3 at $8000 here); the next F9 removes it
!toggle bp 8000
bl
!toggle bp 8000
bl
